Section 02

数据划分方法

切分遵循时间因果，目标是更接近真实部署中的“过去训练、未来评估”场景。

按天寻找分界点

2.1 总体原则

采用按时间先后顺序的时序切分，而不是随机切分。目标比例为：

Train 60% Valid 20% Test 20%

2.2 划分单位

切分不是逐条交易随机抽样，而是以天为单位寻找分界点，使训练、验证和测试分别覆盖最早、中间和最晚的一段时间窗口。

为什么这样做

这种协议更贴近真实部署场景，能够避免模型在训练中“看见未来”，也更能检验时间漂移下的泛化能力。

Section 03

特征工程梳理

特征工程由两层构成：基础交易特征负责表达交易语义，GFP 图特征负责表达关系结构与时间模式。

默认后端：GFP

3.1 基础交易特征

  • 时间位置特征：小时、星期等。
  • 金额特征：付款金额、到账金额。
  • 银行相关信息：付款银行、收款银行。
  • 类别型信息：支付币种、接收币种、支付方式。

同时会构造金额对数、金额差值、币种是否不一致、是否同银行、是否自环等底层输入属性。

3.2 GFP 特征工程

GFP 图信号主要分为四类，分别对应局部扩散与汇聚、短时回流闭环、多跳循环结构以及节点时窗统计行为。

Scatter-Gather

关注资金是否从某个账户快速分散出去，或从多个来源汇聚进来，适合刻画“拆分转出”“多路归集”这类局部扩散与汇聚模式。

Temporal Cycle

关注资金是否在较短时间窗口内形成回路并回到原路径附近，强调“短周期、带时间约束的闭环”，适合识别快速回流与短时绕转。

Long-cycle / Local-cycle

local-cycle 更偏短路径的小闭环，long-cycle 更偏多跳绕转链路。它们反映资金是否经过多层账户后重新回到原关系网络中。

Vertex Statistics

在一定时间窗内统计交易两端账户的活跃度、金额分布和时间密度，为每条边补充“源点和终点是否像异常枢纽”的背景信息。

3.3 从异常资金流转阶段看 GFP

在欺诈检测场景中，异常资金流转通常可以理解为三个阶段：Placement 是异常资金进入金融系统，资金转移与混淆（Layering）是通过多账户、多路径、多时间窗口转移来隐藏来源与切断追溯链路，Integration 是资金流向看似正常的消费、投资或经营活动中。

阶段 交易图上的典型痕迹 当前特征工程
Placement 异常资金从少数来源账户进入系统，可能表现为短时间内异常入账、金额分布突变、跨银行或跨币种进入。 基础交易特征覆盖金额、币种、银行和支付方式；vertex_stats 在 1 天窗口内补充源点/终点活跃度、时间密度和金额统计，因此能感知"新进入资金是否改变账户近期行为"。但若无实体类型或账户性质等业务字段，进入阶段的语义只能被间接刻画。
资金转移与混淆
（Layering）		 资金被拆分、汇聚、绕转、回流，形成扇出/扇入、scatter-gather、环、随机游走、二部图或多层二部图等子图结构。这是欺诈链条中最核心的隐蔽手段。 这是当前 GFP 覆盖最强的阶段：scatter-gather 捕捉 6 小时内的拆分-归集，temp-cycle 与 lc-cycle 捕捉 1 天内的短时闭环和最长 10 跳循环，vertex_stats 捕捉异常枢纽账户。图专家再通过 PNA 聚合交易边周围的多跳关系上下文。
Integration 资金流向看似正常的收款方、消费、供应链、投资或经营支付，图上更像"异常路径之后的正常出口"。 当前特征能通过目标账户近期入账/出账统计、支付方式、币种、同银行关系和图上下文捕捉部分出口行为；PNA 的边级上下文有助于识别"前序链路异常但当前交易表面正常"的边。限制在于：若没有商户类别、实体所有权、业务关系等字段，退出阶段的业务语义仍主要依赖图结构间接表达。

3.4 八类典型欺诈子图模式与当前特征覆盖

常见欺诈交易模式可以抽象为 8 类交易子图。这些模式在洗钱、套现、虚假交易等多种欺诈类型中均有出现。当前实现更像“模式证据提取器”：对可直接计算的结构显式提取，对需要更高阶语义或更长路径的结构交给统计特征和图专家补足。

模式 子图结构
Fan-out 一个账户向多个不同账户转出。
Fan-in 多个不同账户向同一账户转入。
Gather-scatter 多个来源先汇聚到中心账户，再由该中心账户向多个目标散出。
Scatter-gather 一个来源拆分到多个中间账户，再从这些中间账户归集到一个目标账户。
Simple cycle 资金沿一条简单路径绕转后回到起点账户。
Random 资金在受控账户间随机多跳转移，不一定回到起点。
Bipartite 一组输入账户向一组输出账户转移，形成多对多二部结构。
Stack 在二部结构上再叠加一层或多层中间账户，形成多层资金通道。

3.5 GFP 的输入信息范围

源账户 / 目标账户 金额原值 / 对数值 支付币种 / 接收币种 支付方式编码 是否跨币种 是否同银行 是否自环 时间位置

可以理解为：以交易为中心，在图上对结构、时间和属性做联合编码。

3.6 最终表格中包含什么

基础样本字段 数据切分标记 标签 可选图索引字段 GFP 工程化特征

对表格专家而言，真正提供主要判别力的是 GFP 生成的工程化特征集合。

Section 04

图是怎么构建的

图中的节点是账户实体，图中的边是交易本身，因此图专家天然与边级风险识别任务对齐。

账户作为节点，交易作为有向边

4.1 节点与边

  • 节点由 银行标识 + 账户标识 共同定义。
  • 每一条边对应一笔真实交易。
  • 边标签是该笔交易是否 Fraud。

这样可以避免不同银行中同名账户发生语义混淆，也更贴近实际交易网络中的账户实体定义。

4.2 边属性

每条边除了连接关系本身，还附带交易时间、金额、币种、支付方式以及同银行 / 自环等关系属性，因此图模型并不是只基于拓扑结构做传播。

4.3 双向消息传播

交易图本身是有向的，但为了让局部上下文更充分，图专家在消息传播中会综合正向与反向关系，从而同时感知资金流入与流出两侧的模式。

4.4 graph_build 构建后统计

graph_build/stats.json 给出了构图后的规模、稀疏性、连通性、重边、自环与时间密度。它们说明当前任务不是一个普通表格分类问题，而是一个高度稀疏、极端不平衡、重边密集的有向交易多重图。

4.6 关键发现

  1. 类别极端不平衡。Fraud 仅占 0.102%，所以准确率没有解释力，必须强调 AUPRC、F1、precision、recall 等面向少数类的指标。
  2. 多重边是核心信号。约 80% 的边是重复账户对交易，说明交易频次、顺序和边属性比简单拓扑更重要。
  3. 图结构高度异质。中位总度只有 6，但最大总度达到 169,756，PNA 这类带度缩放的聚合器更适合处理这种长尾度分布。
  4. 方向性不能丢。互惠率只有 0.1454%，资金流向高度非对称；反向消息传播只用于补充上下文，标签预测仍然对应原始有向交易。
  5. 时间密度很高。17.68 天内超过 500 万笔交易，平均间隔约 0.30 秒。
Section 05

两个 Expert 分别做什么

两个 expert 看到的是同一笔交易，但一个擅长表达交易属性，一个擅长表达关系环境，因此天然具有互补性。

图专家主架构：PNA

5.1 Table Expert

XGBoost
  • 消化工程化后的交易级特征。
  • 快速形成稳定的边级判别器。
  • 输出每笔交易的风险分数。
  • 在 Co-EM 中给图专家提供 teacher signal。

优势在于结构化特征利用效率高、训练稳定、对类别不平衡场景友好。

5.2 Graph Expert

PNA GNN
  • 建模账户之间的连接关系与局部子图上下文。
  • 结合边属性学习交易在图中的角色。
  • 输出每条交易边的风险分数。
  • 输出边级 embedding，可用于反向增强表格专家或最终融合。

图专家本质上是一个面向交易边的 GNN expert，而不是节点分类模型。

5.3 双 expert 协作关系

5.4 图专家实际使用了什么输入

  • 图结构：谁向谁转账。
  • 边属性：金额、币种、时间、关系型特征以及 GFP 特征。
  • 时间 / 方向上下文：增强消息传播的时序与方向感知。

互补性总结

Table expert 擅长看单笔交易属性表达，Graph expert 擅长看交易所处的关系环境。二者围绕同一笔交易形成不同视角，因此能在 Co-EM 中互相增强。

Section 06

PNA 模型介绍

PNA 是当前图专家主线。它的重点不是只取邻居均值，而是用多种聚合器和度缩放机制处理交易图中的长尾度分布、枢纽账户与稀疏邻域。

Principal Neighbourhood Aggregation
为什么用 PNA

适合异质交易图

graph_build 统计显示：多数账户总度很低，但极少数账户拥有非常高的连接度。普通均值聚合会把这类结构差异压平；PNA 同时使用 mean、min、max、std 聚合，并配合 degree scaler，让模型能区分“低度账户的一次异常”和“高度账户的异常流量模式”。

聚合机制

多聚合器 + 度缩放

当前实现使用 mean / min / max / std 四类邻域聚合器，以及 identity / amplification / attenuation 三类缩放器。度直方图来自训练图，用来告诉模型不同度数节点的消息应该如何放大或削弱。

边级分类

预测对象仍是交易边

PNA 层先更新账户节点表示，再把源账户表示、目标账户表示和交易边属性拼接成边级 embedding。最终 classifier 输出这笔交易的风险 logit，因此它是边分类模型，而不是节点分类模型。

当前变体

Multi-PNA + Edge Updates

最优 EM 配置中使用 multi-pna-eu。EU 表示每一层都会用源节点、目标节点和当前边表示更新 edge attribute，使“交易边本身”也能随消息传播一起被 refine，而不是只作为静态输入。

Section 07

评价指标说明

本任务的 Fraud 正例只有 0.102%，所以评估重点必须围绕少数类检测能力，而不是总体准确率。

AUPRC 为主指标
Ranking Metric

AUPRC

Area under Precision-Recall Curve

AUPRC 衡量模型把 Fraud 样本排在前面的能力，覆盖所有阈值下 precision 与 recall 的权衡。正例极少时，ROC-AUC 或 accuracy 容易被大量负例稀释；AUPRC 更直接反映“报警列表前排是否真的有 Fraud”。

Threshold Metric

F1

F1 = 2 * P * R / (P + R)

F1 是 precision 与 recall 的调和平均，用来评价选定阈值后的综合检测效果。它会惩罚只追求高 precision 或只追求高 recall 的极端方案，适合作为阈值选择后的总体少数类指标。

Alert Quality

Precision

Precision = TP / (TP + FP)

Precision 表示被模型报为 Fraud 的交易中，有多少是真的 Fraud。它对应风控运营里的告警质量：precision 越高，人工审核或后续拦截的无效成本越低。

Detection Coverage

Recall

Recall = TP / (TP + FN)

Recall 表示真实 Fraud 中有多少被模型抓到。它对应风险覆盖率：recall 越高，漏掉的欺诈交易越少；但 recall 通常需要与 precision 一起看，避免用大量误报换覆盖。

为什么同时选择这四个指标

AUPRC 负责阈值无关的排序质量，F1 负责验证集选定阈值后的综合效果，precision 与 recall 分别刻画误报成本和漏报风险。阈值、fusion 权重和最佳 head 均在验证集上选择，再固定到测试集评估，确保泛化能力评估的客观性。

Section 09

Co-EM 方法论解释

Co-EM 的目标不是简单拼接两个模型，而是让表格专家与图专家在训练阶段发生受控的信息交换：先 warmup 建立可靠起点，再用低权重、高约束的伪标签进行协同。

先 warmup，再协同，再融合
1

9.1 整体流程

  1. 先训练初始表格专家。
  2. 再用真实标签 warmup 图专家。
  3. 随后交换软标签与分数信息进入 EM 轮次。
  4. 最后比较 table、gnn、fusion 三个 head。
2

9.2 Warmup 为什么必要

Warmup 阶段让表格专家先学稳定的 GFP 表征，让图专家先只用训练集真实标签学习基本边判别能力。这样进入 EM 时，两个 expert 都不是随机状态，互相传递的信号更少被早期噪声污染。

3

9.3 EM 轮次做什么

表格专家输出校准概率并筛选 teacher signal 训练图专家；图专家再输出风险分数和边级 embedding，作为后续融合或表格侧可选增强信号。最终在验证集选择 table、gnn 或 fusion head。

9.5 什么是伪标签

伪标签是模型给样本生成的“教师信号”。它可以是硬类别，也可以是概率。在当前 Co-EM 中，更重要的是概率型伪标签：表格专家对某笔交易输出 Fraud 概率，经校准后作为图专家的 teacher probability。

直观理解：真实标签来自数据标注，伪标签来自另一个 expert 的高置信预测。

9.6 伪标签在哪里使用

Table → Graph 方向，表格专家的 teacher probability 会进入图专家训练 loss；Graph → Table 方向，图专家输出的 score 和 edge embedding 可以作为可选表格特征或融合输入。也就是说，伪标签主要用于训练阶段的互教，最终测试集只用于评估。

当前最优配置中，图专家伪标签权重 gnn_pl_weight=0.1，table_gnn_feature_mode=none，因此本次增益主要体现在受控图训练与最终 fusion，而不是把 GNN embedding 直接追加给表格模型。

9.7 与普通标签的区别

普通标签是人工或数据集给出的 gold label，在图专家 loss 中使用真实 0/1 目标，并带有正负样本不平衡权重。伪标签是 teacher probability，使用 soft target 训练，权重更低，作用是补充信息而不是覆盖真实标签。

这使模型能利用更多样本的 teacher signal，同时避免把 teacher 的错误当成确定事实。

9.8 为什么只选高置信伪标签

伪标签最大风险是确认偏差：teacher 错了，student 会把错信号学进去，下一轮再放大。因此需要限制来源、置信度和数量。实现里支持 train / valid / both 来源选择、最小置信度门槛，以及每类最多样本数限制。

当前实验中实际进入 GNN 的伪标签为 20,692 条，平均 confidence 约为 0.992，通过来源限制、置信度门槛和每类样本数上限进行多重约束。

9.10 软标签、校准与最终融合

协同过程中传递的不只是硬标签，而是概率型信息。两个 expert 的分数会先做概率校准，再用于伪标签筛选、后续训练和最终融合。 最终还会在验证集上搜索 table 与 gnn 的最优权重组合，形成 Table-only、GNN-only 与 Table-GNN fusion 三类候选 head。

Section 10

方法概述

该方法围绕边级交易识别任务，将交易属性建模、关系结构建模与协同学习机制整合为统一流程。

整体方法摘要
针对欺诈交易检测任务，构建了一套严格遵循时序切分的边级检测流程。系统先基于交易属性与图结构生成工程化特征，再分别训练表格专家和图专家，其中表格专家擅长刻画单笔交易属性模式，图专家擅长建模账户间资金流动关系。两者通过 Co-EM 机制交换软标签与关系表示，并在验证集上完成校准、阈值选择与融合权重选择，最终以 AUPRC 为主指标评估在未来时间窗口上的泛化能力。

整体设计强调三点：严格时序评估、图表互补建模，以及在验证集约束下完成校准、协同与融合。
